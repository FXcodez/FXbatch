FXbatch Resizer

Batch Image Resizer and Optimizer

User Guide

Reference documentation and workflow guide for version 2.0.0

Overview

FXbatch Resizer is a desktop application for bulk image downscaling, format conversion, and DPI resampling. It distributes jobs across all available logical CPU cores using Python's multiprocessing pool, processing directories of images quickly without freezing the user interface.

Processing is non-destructive: original files remain untouched in their source directory, while converted images are saved to a dedicated subfolder (by default, LowRes).

Quick start

  1. Select an input folder: Drag a folder directly into the dropzone, or click Browse to select a directory on your drive.
  2. Review sample analysis: The application picks a sample file and calculates projected dimensions and compression savings in memory before any conversion begins.
  3. Set output parameters: Adjust the quality level, resize percentage, target DPI, and output image format.
  4. Confirm destination: Converted files save to a LowRes subfolder inside your source directory. You can specify a different folder path or change the default subfolder name in Settings.
  5. Run the batch: Click Batch Convert Images. The progress bar tracks completion, and the activity log records per-file operations.

Parameter controls

Quality (10 to 100)

Controls compression quantization for JPEG and WebP. A setting of 60 offers a balanced compromise between file size and visual fidelity for digital proofs and web galleries. Values from 85 to 90 preserve fine detail for portfolio masters. PNG files use lossless compression and ignore this setting.

Resize scale (10% to 100%)

Scales pixel dimensions proportionally using high-quality Lanczos resampling. The engine reads camera EXIF orientation tags and corrects rotation before scaling, preventing distorted aspect ratios.

Output format (JPG, PNG, WEBP)

Converts files between JPEG, PNG, and WebP containers. When saving transparent images to JPEG, alpha transparency is flattened against a solid white matte.

Target DPI (72 to 3000)

Sets embedded metadata resolution tags for publishing and layout software without altering the physical pixel dimensions of the image.

Sample preview and telemetry

When a folder is selected, FXbatch samples an image and simulates compression in memory using Pillow BytesIO buffers. This preview measures size reduction without writing temporary files to disk.

Activity log and batch processing

The activity log displays live progress while a conversion runs:

  • Parallel execution: Images are allocated across CPU cores with Python's ProcessPoolExecutor. UI updates are handled through a non-blocking queue polling loop every 20 milliseconds.
  • Warmup phase: The progress bar advances along a 2.5-second warmup curve during the first 10% while worker processes spin up.
  • Completion summary: Once processing finishes, the activity log prints total images processed, error count, elapsed time, and total disk space saved. The log automatically scrolls to the top of the summary for immediate review.
  • Cancellation: Clicking Cancel Processing or pressing Escape halts active execution safely. Files that finished before cancellation remain saved in the destination folder.

Settings and preferences

Click the Settings button in the sidebar to open the configuration dialog:

  • Startup theme: Choose between Dark, Light, or System to determine which theme loads when the application starts.
  • Default values: Set your preferred startup values for Quality, Resize scale, and DPI.
  • Subfolder name: Customize the default subfolder name (default: LowRes). Preferences are saved to config.ini.
